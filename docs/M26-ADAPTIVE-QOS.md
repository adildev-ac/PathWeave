# M2.6 Adaptive QoS

`--qos-mode adaptive` adds independent upload and download controllers for each configured adapter with an explicit `--interface-capacity-mbps INDEX=DOWNLOAD:UPLOAD` value. Capacity is user-supplied sustainable Internet capacity; physical adapter link speed and observed throughput are not used as capacity estimates. A known-direction rate starts at `capacity × --qos-adaptive-target-percent` (default 90%), capped by an explicit `--qos-interface-limit` / GUID cap if present.

The controller consumes fresh QoS lane p95 sojourn samples and Windows interface error/discard ratios. It does not use the existing TCP connection-establishment probe as RTT. A single noisy sample does not change a rate: a decrease needs three consecutive congested samples (25 ms queue delay by default or at least 2% interface error/discard ratio). Recovery needs five samples below 10 ms and 0.5% errors. A decrease uses a 0.85 multiplicative factor, bounded to 15% per control interval. Recovery adds 5% of configured capacity per change, also bounded to 15%, and observes a four-second cooldown. The controller clamps to configured minimum and maximum rates.

Controls are separate per interface and direction. If capacity is unknown, that direction stays unshaped unless a fixed per-interface limit was provided. Stale queue data moves the controller to `InsufficientData` and retains its last safe rate. No automatic speed test runs. `--qos-adaptive-interval-secs`, `--qos-adaptive-min-mbps`, `--qos-adaptive-target-delay-ms`, and `--qos-adaptive-recovery-delay-ms` tune the initial controller.

The first controller uses local userspace queue delay and interface errors/discards. It does not measure pure Internet RTT, loaded latency inflation, jitter, probe-target health, or carrier-path loss. Queue delay can reflect demand against the configured shaper and should be interpreted with that limitation. JSON diagnostics show current rate, state, and observation confidence. These controllers are application-level rate managers; TCP congestion control remains in the OS/userspace TCP stacks.
